Not a full production agent. Module 4 builds a coding agent so you get intuition for how tools like Cursor and Lovable work under the hood - it's deliberately not a deep, multi-agent framework course. If you want to go deeper into building agents, see the [LLM Zoomcamp](https://github.com/DataTalksClub/llm-zoomcamp).
