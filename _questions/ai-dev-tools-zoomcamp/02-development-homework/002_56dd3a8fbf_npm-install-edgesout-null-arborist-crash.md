question: "npm install crashes with \"TypeError: Cannot read properties of null (reading 'edgesOut')\". How do I fix it?"
sort_order: 2
---

This is a crash inside npm's dependency resolver (Arborist), not a bug in your code. It's usually triggered by an inconsistent `node_modules` or `package-lock.json`, for example in a prototype generated by another tool, or after an interrupted install.

Try these in order:

1. Reinstall from scratch:

   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

   In PowerShell: `Remove-Item -Recurse -Force node_modules, package-lock.json`.

2. Upgrade npm and retry:

   ```bash
   npm install -g npm@latest
   ```

3. If it only fails when you add test tooling, pin the vitest major version that the [reference app](https://github.com/alexeygrigorev/interview-canvas-share) uses (quote the range so your shell doesn't interpret `^`):

   ```bash
   npm install -D "vitest@^4.1.0" jsdom @testing-library/react @testing-library/dom
   ```

Once it installs, commit `package-lock.json`. Anyone who clones your repo can then run `npm ci`, which installs exactly the locked tree.
