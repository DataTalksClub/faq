question: "MCP Inspector shows a 'Connection Error'. Can I skip it?"
sort_order: 2
---

Yes, you can skip MCP Inspector. As long as your editor (VS Code, Cursor, Antigravity, etc.) can connect to your MCP server, you're fine. For practice you can also write your own MCP client - see the example in [toyaikit](https://github.com/alexeygrigorev/toyaikit/blob/main/toyaikit/mcp/client.py).
