question: 'Will this course teach me to build a production AI agent?'
sort_order: 8
---

Not a full production agent. Unit 5 has you extend a coding agent (MCP, skills, custom loops) so you get intuition for how tools like Cursor and Lovable work under the hood - it's deliberately not a deep, multi-agent framework course. If you want to go deeper into building agents, see the [LLM Zoomcamp](https://github.com/DataTalksClub/llm-zoomcamp).
