question: Do I have to use Django for Homework 1 if I want to build with a different
  stack?
sort_order: 4
---

Yes, use Django for Homework 1. The multiple-choice questions are based on the
Django project, so the answers won't match with another stack.

You can still get value from your own stack. Get the homework answers with
Django, and AI can help with that. Then build what you want with the tools you
prefer.
