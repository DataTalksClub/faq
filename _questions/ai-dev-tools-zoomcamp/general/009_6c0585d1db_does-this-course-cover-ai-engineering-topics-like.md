question: 'Does this course cover AI engineering topics like LangChain, vector databases, or RAG?'
sort_order: 9

No. This course is about using AI dev tools to be a more productive developer, not about building LLM applications. LangChain/LangGraph, vector databases, retrieval, and reranking are AI engineering topics - those are covered in the free [LLM Zoomcamp](https://github.com/DataTalksClub/llm-zoomcamp). The only overlap is Module 4, where you build a coding agent to understand how these tools work under the hood.
