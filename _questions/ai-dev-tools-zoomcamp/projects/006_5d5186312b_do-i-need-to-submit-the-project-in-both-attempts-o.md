question: Do I need to submit the project in both attempts, or can I submit an improved
  version of the same project in attempt 2?
sort_order: 6
---

No. One passing project is enough for the certificate.

The second attempt is a second chance, not a second project. Use it if you
missed the first attempt's deadline or didn't pass it. In that case you can
improve the same project and submit it in attempt 2.

If you passed the first attempt, don't submit the same project again in
attempt 2, even with added features. Resubmitting work that has already been
evaluated would be self-plagiarism.
