question: Can I use AI tools like ChatGPT, Claude, or Cursor to write code for the
  capstone project?
sort_order: 25
---

Yes. AI tools are allowed for homework, the project, and peer reviews.

What we ask is that you understand what you submit. If a peer reviewer asks why
you picked a particular chunking strategy, retrieval setup, or orchestrator, you
should be able to explain it. Document your AI usage in the README when AI shaped
major decisions - it is good practice and helps reviewers. You are not required to
disclose AI usage otherwise, and there is no form to sign.

The full rules are in the
[AI usage policy](https://datatalks.club/docs/courses/zoomcamp-logistics/ai-usage/).
