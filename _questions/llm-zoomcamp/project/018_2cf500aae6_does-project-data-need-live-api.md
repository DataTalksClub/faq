question: Does my capstone project data need to come from a live API?
sort_order: 18
---

No, you can use a static file, a self-created dataset, or an API-backed source.
For full reproducibility points, make the data accessible and provide a script
that lets reviewers rebuild the knowledge base. See the
[project evaluation criteria](https://github.com/DataTalksClub/llm-zoomcamp/blob/main/project.md#evaluation-criteria)
for the ingestion and reproducibility requirements.
