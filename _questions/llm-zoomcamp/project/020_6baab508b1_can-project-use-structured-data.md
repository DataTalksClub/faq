question: Does the capstone project need a document-based dataset?
sort_order: 20
---

No, you can use structured data such as database schemas, table descriptions,
or records. You still need to retrieve or query the data as part of an
end-to-end RAG or agent flow. Evaluate that flow against the
[project criteria](https://github.com/DataTalksClub/llm-zoomcamp/blob/main/project.md#evaluation-criteria).
