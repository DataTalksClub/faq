question: Is there a minimum dataset size for the capstone project?
sort_order: 17
---

No, you don't need a minimum dataset size for the capstone project. Choose
enough data to demonstrate and meaningfully evaluate your retrieval or agent
flow. Reviewers assess the project using the
[published evaluation criteria](https://github.com/DataTalksClub/llm-zoomcamp/blob/main/project.md#evaluation-criteria),
not by counting documents or rows.
