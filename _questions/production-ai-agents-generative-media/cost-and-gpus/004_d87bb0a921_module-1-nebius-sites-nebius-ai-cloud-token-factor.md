question: Which Nebius sites does Module 1 use (Nebius AI Cloud vs Token Factory)?
sort_order: 4
---

Module 1 uses Nebius AI Cloud (`console.nebius.com`) only. You do not need Token Factory credits for Module 1 or Homework 1.

- Nebius AI Cloud (`console.nebius.com`): used for all of Module 1 (Serverless AI → Endpoints, Jobs, DevLabs).
- Token Factory (`tokenfactory.nebius.com`): serves LLMs behind an OpenAI-compatible API; the course starts using it in Module 2 for agents (though you may use your own LLM provider there too).
- Accounts & billing: one Builder Program application issues both promo codes, but each Nebius site (`console...` vs `tokenfactory...`) requires its own account and you must apply the promo code separately under Billing.
