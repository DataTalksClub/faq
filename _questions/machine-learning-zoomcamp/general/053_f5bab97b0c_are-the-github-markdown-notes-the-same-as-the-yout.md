question: Are the GitHub markdown notes the same as the YouTube videos? Which one
  should I follow?

Follow the videos: they're the original lessons.

The markdown notes and transcripts in the GitHub repository were created
automatically from the YouTube videos using AI. They cover the same lessons,
but they can contain mistakes. Use them as a companion to the videos, and if
they disagree with a video, follow the video.

If you notice a mistake in the notes, please open a pull request with a fix in
the [course repository](https://github.com/DataTalksClub/machine-learning-zoomcamp).
