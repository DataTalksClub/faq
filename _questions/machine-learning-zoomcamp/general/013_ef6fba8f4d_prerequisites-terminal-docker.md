question: What are the prerequisites for the course?
sort_order: 13
---

You need to be able to program and to feel comfortable working in the terminal.
That means running commands, reading error messages, and using Git. Without
that, the course will be hard to follow.

You don't need to know Docker before you start. Docker is taught in Module 5
(deployment).

If you're new to the command line, do some hands-on practice before the course
starts. You don't need to master everything on day one, but basic comfort with
the terminal will help you keep up.
